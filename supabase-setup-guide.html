🛰️ راهنمای کامل اتصال شبکهٔ یادآور

۶ مرحلهٔ ساده — حدود ۱۰ دقیقه — فقط یک بار برای همیشه. برای چت دوطرفه، گروه تسک مشترک، پاس دادن تسک و تماس صوتی.

۱ ساخت حساب در سایت (۲ دقیقه)

  1. در مرورگر باز کنید: supabase.com
  2. بالای صفحه دکمهٔ Start your project (یا Sign In) را بزنید.
  3. ساده‌ترین راه: Continue with Google — با جیمیل خودتان وارد شوید. (اگر گوگل ندارید: «Sign up» → ایمیل + پسورد → کد تأییدی که به ایمیلتان می‌آید را وارد کنید.)
  4. اگر پرسید Organization چیست، همان پیش‌فرض (شخصی) را قبول کنید.

۲ ساخت پروژهٔ رایگان (۳ دقیقه)

  1. در داشبورد، دکمهٔ سبز New project را بزنید.
  2. در پنجرهٔ بازشده:
    • Name → بنویسید yadavar
    • Database Password → دکمهٔ Generate a password را بزنید و آن پسورد را در یادداشت گوشی ذخیره کنید (فقط برای ورود به سایت است؛ در برنامه وارد نمی‌شود) و تیک «Saved my password» را بزنید.
    • Region → اگر گزینه بود Mumbai یا Bahrain (نزدیک‌تر به ایران)؛ نبود، هرکدام.
  3. دکمهٔ Create new project را بزنید و حدود ۲ دقیقه صبر کنید تا پروژه آماده شود.

۳ کپی دو مقدار لازم

  1. داخل پروژه، بالای صفحه دکمهٔ Connect را بزنید. پنجره‌ای باز می‌شود که Project URL (شبیه https://abcd1234.supabase.co) و Publishable key (شبیه sb_publishable_…) را نشان می‌دهد.
  2. کنار هر کدام دکمهٔ کپی 📋 هست — هر دو را کپی و در یادداشت گوشی ذخیره کنید.
  3. اگر در آن پنجره نبود: منوی چپ، پایین صفحه، چرخ‌دندهٔ ⚙ Settings → API Keys → کنار Publishable key دکمهٔ کپی.
  4. نکته: کلید قدیمی که با eyJ… شروع می‌شود (برچسب anon) هم کار می‌کند؛ هر کدام را دیدید همان.
⚠️ کلید service_role یا secret را هرگز کپی و وارد نکنید. فقط کلید «Publishable» یا «anon» مجاز است.
⭐ از نسخهٔ v248: این دو مقدار به‌صورت پیش‌فرض داخل برنامهٔ یادآور ثبت شده‌اند — اعضای خانواده فقط «نام نمایشی» را می‌نویسند و «ذخیره و اتصال» می‌زنند. اگر فرم را عوض کرده‌اید، دکمهٔ «↺ پیش‌فرض» در پنل شبکه همین مقادیر را برمی‌گرداند؛ «⛔ قطع اتصال و پاک کردن» هم شبکه را خاموش می‌کند.

۴ اجرای اسکریپت SQL (یک بار برای همیشه)

  1. منوی چپ سایت → آیکون SQL Editor (شبیه >_) را بزنید.
  2. دکمهٔ New query (+) را بزنید — یک کادر خالی باز می‌شود.
  3. از دکمهٔ سبز پایینِ همین بخش، اسکریپت را کپی کنید (یا در خود برنامهٔ یادآور: منوی ☰ → 🛰️ شبکه → دکمهٔ «📋 کپی اسکریپت SQL») و داخل کادر پیست کنید.
  4. دکمهٔ سبز Run (پایین صفحه) یا Ctrl+Enter را بزنید.
✅ پیام «Success. No rows returned» یعنی موفق — ۴ جدول شبکه ساخته شد. این مرحله فقط یک بار لازم است.
اگر دوباره Run کنید و خطای «already exists» دیدید، عیبی ندارد — یعنی قبلاً ساخته شده.
-- یاداوار شبکه — یک بار در SQL Editor پروژهٔ Supabase اجرا شود
create extension if not exists pgcrypto;
create table if not exists net_groups (
  id uuid primary key default gen_random_uuid(),
  code text unique not null,
  name text not null,
  created_by text not null,
  created_at timestamptz default now()
);
create table if not exists net_members (
  group_id uuid references net_groups(id) on delete cascade,
  user_id text not null,
  display_name text not null,
  joined_at timestamptz default now(),
  primary key (group_id, user_id)
);
create table if not exists net_tasks (
  id uuid primary key default gen_random_uuid(),
  group_id uuid references net_groups(id) on delete cascade,
  title text not null,
  deadline date,
  owner_id text not null,
  owner_name text not null,
  assignee_id text,
  assignee_name text,
  done boolean not null default false,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);
create table if not exists net_messages (
  id uuid primary key default gen_random_uuid(),
  group_id uuid references net_groups(id) on delete cascade,
  sender_id text not null,
  sender_name text not null,
  text text not null,
  created_at timestamptz default now()
);
alter table net_groups enable row level security;
alter table net_members enable row level security;
alter table net_tasks enable row level security;
alter table net_messages enable row level security;
create policy "net_groups_all" on net_groups for all using (true) with check (true);
create policy "net_members_all" on net_members for all using (true) with check (true);
create policy "net_tasks_all" on net_tasks for all using (true) with check (true);
create policy "net_messages_all" on net_messages for all using (true) with check (true);

۵ وصل کردن برنامهٔ یادآور

  1. برنامهٔ یادآور را باز کنید (اگر نسخهٔ جدید نبود، دوبار رفرش کنید).
  2. منوی ☰ (همبرگری) → 🛰️ شبکه
  3. فرم را پر کنید:
    • آدرس پروژه → همان Project URL مرحلهٔ ۳
    • کلید عمومی → همان Publishable key مرحلهٔ ۳
    • نام نمایشی → مثلاً «مامان» یا «پدر» (همین نام در چت و اعضا دیده می‌شود)
  4. دکمهٔ ذخیره و اتصال را بزنید.
✅ وقتی بالای پنل نوشت «متصل ✓» همه‌چیز آماده است.

۶ ساخت گروه و دعوت بقیه

  1. در پنل شبکه، تب 👥 گروه‌ها → نام گروه (مثلاً «خانواده») → دکمهٔ ساخت گروه.
  2. یک کد دعوت ۶ حرفی نمایش داده می‌شود — آن را برای اعضای خانواده/همکاران بفرستید.
  3. هر نفر روی گوشی خودش فقط مرحلهٔ ۵ را انجام می‌دهد، بعد: تب گروه‌ها → «عضویت با کد دعوت» → کد شما.
  4. حالا: تب 💬 چت گروه، تب ✅ تسک‌های گروه (با «پاس دادن»)، و دکمهٔ 📞 تماس کنار اسم هر عضوِ آنلاین.
برای تماس صوتی، مرورگر یک بار اجازهٔ میکروفون می‌پرسد → «اجازه دادن / Allow» بزنید.
