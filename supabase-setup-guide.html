🛰️ راهنمای کامل اتصال شبکهٔ یادآور

۶ مرحلهٔ ساده — حدود ۱۰ دقیقه — فقط یک بار برای همیشه. برای چت دوطرفه، گروه تسک مشترک، پاس دادن تسک و تماس صوتی.

۱ ساخت حساب در سایت (۲ دقیقه)

  1. در مرورگر باز کنید: supabase.com
  2. بالای صفحه دکمهٔ Start your project (یا Sign In) را بزنید.
  3. ساده‌ترین راه: Continue with Google — با جیمیل خودتان وارد شوید. (اگر گوگل ندارید: «Sign up» → ایمیل + پسورد → کد تأییدی که به ایمیلتان می‌آید را وارد کنید.)
  4. اگر پرسید Organization چیست، همان پیش‌فرض (شخصی) را قبول کنید.

۲ ساخت پروژهٔ رایگان (۳ دقیقه)

  1. در داشبورد، دکمهٔ سبز New project را بزنید.
  2. در پنجرهٔ بازشده:
    • Name → بنویسید yadavar
    • Database Password → دکمهٔ Generate a password را بزنید و آن پسورد را در یادداشت گوشی ذخیره کنید (فقط برای ورود به سایت است؛ در برنامه وارد نمی‌شود) و تیک «Saved my password» را بزنید.
    • Region → اگر گزینه بود Mumbai یا Bahrain (نزدیک‌تر به ایران)؛ نبود، هرکدام.
  3. دکمهٔ Create new project را بزنید و حدود ۲ دقیقه صبر کنید تا پروژه آماده شود.

۳ کپی دو مقدار لازم

  1. داخل پروژه، بالای صفحه دکمهٔ Connect را بزنید. پنجره‌ای باز می‌شود که Project URL (شبیه https://abcd1234.supabase.co) و Publishable key (شبیه sb_publishable_…) را نشان می‌دهد.
  2. کنار هر کدام دکمهٔ کپی 📋 هست — هر دو را کپی و در یادداشت گوشی ذخیره کنید.
  3. اگر در آن پنجره نبود: منوی چپ، پایین صفحه، چرخ‌دندهٔ ⚙ Settings → API Keys → کنار Publishable key دکمهٔ کپی.
  4. نکته: کلید قدیمی که با eyJ… شروع می‌شود (برچسب anon) هم کار می‌کند؛ هر کدام را دیدید همان.
⚠️ کلید service_role یا secret را هرگز کپی و وارد نکنید. فقط کلید «Publishable» یا «anon» مجاز است.
⭐ از نسخهٔ v248: این دو مقدار به‌صورت پیش‌فرض داخل برنامهٔ یادآور ثبت شده‌اند — اعضای خانواده فقط «نام نمایشی» را می‌نویسند و «ذخیره و اتصال» می‌زنند. اگر فرم را عوض کرده‌اید، دکمهٔ «↺ پیش‌فرض» در پنل شبکه همین مقادیر را برمی‌گرداند؛ «⛔ قطع اتصال و پاک کردن» هم شبکه را خاموش می‌کند.

۴ اجرای اسکریپت SQL (یک بار برای همیشه)

  1. منوی چپ سایت → آیکون SQL Editor (شبیه >_) را بزنید.
  2. دکمهٔ New query (+) را بزنید — یک کادر خالی باز می‌شود.
  3. از دکمهٔ سبز پایینِ همین بخش، اسکریپت را کپی کنید (یا در خود برنامهٔ یادآور: منوی ☰ → 🛰️ شبکه → دکمهٔ «📋 کپی اسکریپت SQL») و داخل کادر پیست کنید.
  4. دکمهٔ سبز Run (پایین صفحه) یا Ctrl+Enter را بزنید.
✅ پیام «Success. No rows returned» یعنی موفق — ۴ جدول شبکه ساخته شد. این مرحله فقط یک بار لازم است.
اگر دوباره Run کنید و خطای «already exists» دیدید، عیبی ندارد — یعنی قبلاً ساخته شده.
-- یاداوار شبکه — یک بار در SQL Editor پروژهٔ Supabase اجرا شود
create extension if not exists pgcrypto;
create table if not exists net_groups (
  id uuid primary key default gen_random_uuid(),
  code text unique not null,
  name text not null,
  created_by text not null,
  created_at timestamptz default now()
);
create table if not exists net_members (
  group_id uuid references net_groups(id) on delete cascade,
  user_id text not null,
  display_name text not null,
  joined_at timestamptz default now(),
  primary key (group_id, user_id)
);
create table if not exists net_tasks (
  id uuid primary key default gen_random_uuid(),
  group_id uuid references net_groups(id) on delete cascade,
  title text not null,
  deadline date,
  owner_id text not null,
  owner_name text not null,
  assignee_id text,
  assignee_name text,
  done boolean not null default false,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);
create table if not exists net_messages (
  id uuid primary key default gen_random_uuid(),
  group_id uuid references net_groups(id) on delete cascade,
  sender_id text not null,
  sender_name text not null,
  text text not null,
  created_at timestamptz default now()
);
alter table net_groups enable row level security;
alter table net_members enable row level security;
alter table net_tasks enable row level security;
alter table net_messages enable row level security;
create policy "net_groups_all" on net_groups for all using (true) with check (true);
create policy "net_members_all" on net_members for all using (true) with check (true);
create policy "net_tasks_all" on net_tasks for all using (true) with check (true);
create policy "net_messages_all" on net_messages for all using (true) with check (true);

alter table net_messages add column if not exists img text;

۵ وصل کردن برنامهٔ یادآور

  1. برنامهٔ یادآور را باز کنید (اگر نسخهٔ جدید نبود، دوبار رفرش کنید).
  2. منوی ☰ (همبرگری) → 🛰️ شبکه
  3. فرم را پر کنید:
    • آدرس پروژه → همان Project URL مرحلهٔ ۳
    • کلید عمومی → همان Publishable key مرحلهٔ ۳
    • نام نمایشی → مثلاً «مامان» یا «پدر» (همین نام در چت و اعضا دیده می‌شود)
  4. دکمهٔ ذخیره و اتصال را بزنید.
✅ وقتی بالای پنل نوشت «متصل ✓» همه‌چیز آماده است.

۶ ساخت گروه‌ها، پیوستن و مدیریت آن‌ها (از v256 — چند گروه هم‌زمان)

  1. در پنل شبکه، تب 👥 گروه‌ها → کارت «ساخت گروه جدید» → نام گروه → ساخت گروه. گروه بلافاصله با نشان 🛰️ در صفحهٔ اصلی برنامه هم ساخته می‌شود.
  2. یک کد دعوت ۶ حرفی نمایش داده می‌شود — آن را برای اعضای خانواده/همکاران بفرستید.
  3. پیوستن: هر نفر مرحلهٔ ۵ را انجام می‌دهد، بعد در تب گروه‌ها کارت «پیوستن با کد دعوت» → کد را وارد → دکمهٔ 🔑 پیوستن به گروه. این کارت همیشه در تب گروه‌ها هست — حتی اگر قبلاً گروه داشته باشید.
  4. چند گروه: می‌توانید عضو چند گروه باشید؛ همه فعال‌اند و در لیست گروه‌های صفحهٔ اصلی همه را می‌بینید. برای چت/صوتِ هر گروه، در تب گروه‌ها دکمهٔ ✅ فعال همان گروه را بزنید — آن گروه به بالا می‌آید و فعال می‌شود.
  5. مدیریت گروه (فقط سازنده): فقط سازنده دکمهٔ «✏️ ویرایش» (تغییر نام — بلافاصله روی سرور و صفحهٔ اصلی همهٔ اعضا عوض می‌شود) و «🗑 حذف گروه» را دارد و نمی‌تواند از گروه خارج شود. عضو عادی نمی‌تواند حذف کند — فقط «🚪 خروج» دارد.
  6. حالا: تب 💬 چت گروه (صوتی گروهی + عکس)، و دکمهٔ 📞 تماس کنار اسم هر عضوِ آنلاین.
  7. اعضا: تب دوم پنل شبکه «🧑‍🤝‍🧑 اعضا» است — اعضای گروه فعال با وضعیت آنلاین و دکمهٔ تماس. (تسک‌ها در پنل نمایش داده نمی‌شوند؛ همه‌چیز در صفحهٔ اصلی برنامه است.)
  8. تسک‌ها: افزودن و ویرایش تسک‌های گروه 🛰️ دقیقاً به شیوهٔ خود برنامه انجام می‌شود: داخل گروه، دکمهٔ + را بزنید — در فرم یادداشت، ردیف «📤 مسئول انجام» ظاهر می‌شود (پیش‌فرض: خودتان). با «✏️ ویرایش» هر تسک هم همان فرم با مسئول فعلی باز می‌شود. اگر گروهِ یک تسکِ عادی را به گروه 🛰️ تغییر دهید، خودکار به شبکه اضافه می‌شود (ایجادکننده و مسئول = خودتان).
برای تماس صوتی، مرورگر یک بار اجازهٔ میکروفون می‌پرسد → «اجازه دادن / Allow» بزنید. ویرایش/حذف گروه فقط برای سازندهٔ آن گروه فعال است.

۷ بک‌اند موازی گیت‌هاب (اختیاری — بدون سرور واسط)

از نسخهٔ v254 در فرم اتصال می‌توانید «بک‌اند» را بین ☁️ Supabase و 🐙 گیت‌هاب انتخاب کنید. در حالت گیت‌هاب همهٔ داده‌های شبکه (گروه‌ها، اعضا، تسک‌ها، پیام‌ها) در یک فایل JSON داخل یک Gist خصوصی در حساب گیت‌هاب خودتان ذخیره می‌شود و با تأخیر حداکثر ۴ ثانیه بین اعضا هم‌گام می‌شود. تماس صوتی و نشانگر «آنلاین» فقط در بک‌اند Supabase هست.

  1. در GitHub: Settings → Developer settings → Personal access tokens → «Generate new token» → فقط تیک gist را بزنید → توکن را کپی کنید.
  2. در فرم اتصال برنامه: بک‌اند را «گیت‌هاب» بگذارید، توکن را جایگذاری کنید و دکمهٔ 🆕 ساخت Gist جدید را بزنید — شناسهٔ Gist خودکار پر می‌شود.
  3. «ذخیره و اتصال» را بزنید — بالای پنل باید «متصل ✓ (گیت‌هاب)» نوشته شود.
  4. بقیهٔ اعضا: توکنِ خودشان را می‌سازند (مرحلهٔ ۱) و «شناسهٔ Gist» شما را از شما می‌گیرند و در فرمشان وارد می‌کنند؛ گروه و کد دعوت مثل قبل کار می‌کند.

۸ چت صوتی گروهی، عکس و ادغام با گروه‌های اصلی (از v255)

  1. گفتگوی صوتی گروهی: در تب 💬 چت گروه دکمهٔ 🎙 صوتی گروهی را بزنید — همهٔ اعضای حاضر صدای همه را می‌شنوند؛ با دکمهٔ 🎙 میک: باز/بسته میکروفون را قطع/وصل کنید. (فقط بک‌اند Supabase)
  2. حاضران بالای چت: بالای چت نام همهٔ اعضای آنلاین دیده می‌شود؛ کنار هرکس که میکروفونش باز باشد نشان 🎙 می‌خورد.
  3. ارسال عکس: دکمهٔ 📷 کنار فیلد پیام — عکس خودکار فشرده می‌شود و ارسال می‌شود؛ با لمس، تمام‌صفحه باز می‌شود.
  4. ترک چت: دکمهٔ 🚪 ترک چت — فعال: با رفتن به هر جای برنامه، ارسال/دریافت صدا و نوتیف چت ادامه می‌یابد؛ غیرفعال: با خروج از چت فقط نوتیف می‌آید و صدا قطع می‌شود.
  5. نوتیف و شمارنده: پیام جدید وقتی داخل چت نیستید با پیام شناور می‌آید و شمارندهٔ قرمز روی تب چت می‌نشیند.
  6. گروه شبکه در برنامهٔ اصلی: گروه شبکه و تسک‌هایش با نشان 🛰️ در لیست گروه‌ها و تسک‌های اصلی برنامه ظاهر می‌شوند — دقیقاً مثل بقیهٔ گروه‌ها. ساخت و ویرایش با دکمهٔ + و «✏️ ویرایش» خود برنامه انجام می‌شود؛ در فرم، ردیف «📤 مسئول انجام» (گروه شبکه‌ای) هست و «📤 پاس دادن به» در جزئیات هر تسک. تیک «انجام شد»، لغو، تعلیق، فوری و پین هم همگی روی سرور ذخیره و به همهٔ اعضا می‌رسند (از v257).
  7. اگر قبلاً اسکریپت SQL را اجرا کرده‌اید، شش خط آخر آن (alter table net_messages … img و پنج alter table net_tasks …) را یک بار دیگر در SQL Editor اجرا کنید تا ارسال عکس و فیلدهای کامل وضعیت تسک فعال شود (از v257).

«اتصال ناموفق»از نسخهٔ v249 یک جعبهٔ قرمز بالای پنل شبکه «دلیل دقیق + راه‌حل فارسی» را نشان می‌دهد — متنش را بخوانید و طبق آن عمل کنید؛ بعد «↻ اتصال دوباره». اگر پیام خطا خالی بود، از نسخهٔ v250 خود برنامه یک درخواست مستقیم به سرور می‌زند و وضعیت واقعی (401/404/قطع اینترنت) را نشان می‌دهد
راهی به فرم اتصال نیستدر نمای اصلی پنل، بالای تب‌ها دکمهٔ ⚙ تنظیمات اتصال هست؛ برای برگشتن، داخل فرم «↩ بازگشت به نمای اصلی» را بزنید (از نسخهٔ v250)
